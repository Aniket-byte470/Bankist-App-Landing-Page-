# 🌐 Bankist Landing Page

A beautiful, responsive, and interactive landing page for a fictional bank. Built using modern **HTML**, **CSS**, and **JavaScript**, this project focuses on advanced UI/UX features, DOM manipulation, and performance optimization techniques like lazy loading and intersection observers.

---

## 🚀 Features

- 🧭 **Smooth Scrolling Navigation**
- 🪄 **Tabbed Interface** for feature descriptions
- 📌 **Sticky Navigation** using Intersection Observer API
- 🖼️ **Lazy Loading Images** for performance boost
- 🔍 **Section Reveal on Scroll** animations
- 🧠 **Efficient Event Delegation** and DOM traversal
- 📱 **Fully Responsive Design**

---

## 🛠 Tech Stack

- **HTML5** – Semantic and accessible structure
- **CSS3** – Flexbox, Grid, and transitions for styling
- **JavaScript (ES6+)** – Interactivity and scroll-based animations
- **Intersection Observer API** – For sticky nav, reveals, and lazy loading
